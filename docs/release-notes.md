## 中文

Windows 任务栏和 macOS 菜单栏已合并到一个项目，保留双行剩余额度、恢复时间、透明背景和自启动。两端支持中文、日本語、English，附三语言说明。

- Windows：下载 `windows-x64.zip`，解压后运行 `install.cmd`。
- Apple Silicon Mac：下载 `macos-arm64.zip`，解压后运行 `Install.command`。
- Intel Mac：下载 `macos-x64.zip`，解压后运行 `Install.command`。

Mac 旧 App 会备份，语言设置会保存。所有包附 SHA-256。Mac 使用 ad-hoc 签名，未做 Developer ID 公证；也可在 Mac 上从源码构建。

## 日本語

Windows のタスクバー版と macOS のメニューバー版を統合しました。残りの利用枠と回復時刻を2行で常時表示し、透明背景とログイン時の自動起動を保持しています。中文・日本語・English に対応し、3言語の説明を付属しています。

Windows は `windows-x64.zip` を展開して `install.cmd` を実行してください。Mac は Apple Silicon 用の `macos-arm64.zip` または Intel 用の `macos-x64.zip` を展開し、`Install.command` を実行してください。Mac の旧アプリはバックアップされ、言語の選択は保存されます。SHA-256 を付属。Mac は ad-hoc 署名で、公証はありません。ローカルビルドも可能です。

## English

The Windows taskbar and macOS menu-bar apps now share one project and release. Both retain two always-visible quota rows, local reset times, transparent backgrounds and startup at login. Chinese, Japanese and English are supported in the apps and documentation.

Extract `windows-x64.zip` and run `install.cmd`, or select `macos-arm64.zip` (Apple Silicon) / `macos-x64.zip` (Intel) and run `Install.command`. Mac installation backs up existing apps and retains language preferences. SHA-256 checksums are included. Mac apps are ad-hoc signed, without Developer ID notarization; local source builds are available.
